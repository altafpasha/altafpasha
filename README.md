## About

Self-taught security engineer and solo founder running **CodeSec** — a security consulting practice and an AI-powered SaaS vulnerability scanner. Top Rated on Upwork (100% JSS) for DevSecOps and penetration testing work, and an active bug bounty researcher on HackerOne.

Currently deepening the formal side with a BCA in Cybersecurity & AI, stacked on top of the eJPT, BTJA, and CNSP certifications (CRT in progress).

- 🔐 Offensive security — web, mobile, cloud, API
- ⚙️ DevSecOps — secure CI/CD, infra hardening, cloud architecture
- 🛠️ Building — AI-driven security products and automation tooling
- 🎥 Publishing breakdowns and walkthroughs on YouTube
